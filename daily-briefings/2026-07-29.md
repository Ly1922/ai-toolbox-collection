# 每日美工工具挖掘（2026年7月29日）

## 1. 新挖到的美工工具

【studio-vale】+ AI驱动的电商品牌图像生成工作室，可上传产品照片，生成精美的视觉效果，并管理请求，非常适合亚马逊卖家快速制作产品展示图 + https://github.com/mananrh/studio-vale

【planning-ecommerce-image-sets】+ 动态电商图像集规划工具，支持平台和语言适配、提示词生成及内置图像生成质量检查，可用于批量规划亚马逊产品图片套装 + https://github.com/Ma-He1/planning-ecommerce-image-sets

## 2. 抠图 / 场景合成 / 批量出图

【rembg】+ 强大的背景移除工具，可一键去除图片背景，非常适合处理亚马逊产品图的抠图需求 + https://github.com/danielgatis/rembg

【facebookresearch/segment-anything】+ Meta开源的分割一切模型(SAM)，可通过点、框或掩码精确分割图像中的任意对象，完美用于电商产品的精细抠图 + https://github.com/facebookresearch/segment-anything

## 3. ComfyUI / SD 电商工作流

【Comfy-Org/ComfyUI】+ 最强大且模块化的扩散模型GUI、API和后端，具有图形/节点界面，支持复杂的工作流定制，适合构建电商产品图生成管道 + https://github.com/Comfy-Org/ComfyUI

【GroundingDINO】+ 开放集目标检测模型，能够根据文本描述定位图像中的对象，结合ComfyUI可实现精准的产品定位和场景合成 + https://github.com/IDEA-Research/GroundingDINO

## 4. 降本相关（反代/免费API）

【AIClient2API】+ 自托管多协议AI API代理，支持Antigravity、Codex、Grok、Kiro、OpenAI、Claude等多家提供商，提供OpenAI兼容API、智能路由和自动故障转移，有效降低AI服务成本 + https://github.com/justlovemaki/AIClient2API

【Real-ESRGAN】+ 实用的通用图像/视频恢复算法，可显著提升产品图片分辨率和质量，在不增加拍摄成本的情况下获得高清产品图 + https://github.com/xinntao/Real-ESRGAN

今日发现多个高质量的开源工具可用于亚马逊产品图像制作流程，特别是AI抠图和图像放大方面有非常实用的解决方案。建议重点关注rembg进行批量抠图处理，以及利用ComfyUI构建个性化的产品图生成工作流。
