## 4. 降本相关（反代/免费API）

【one-api】【16.8k stars】一个API，汇聚所有大模型。支持 Azure、Anthropic Claude、Google Gemini、智谱、讯飞、通义千问、万相、Emu、Midjourney Proxy等。可用于聚合多个API降低单个模型成本，支持令牌/渠道/分组/用户维度的配额管理。https://github.com/songquanpeng/one-api

【aiclient2api】【2.2k stars】将官方客户端转换为标准 OpenAI API 接口，支持 GPT-4V、Claude、Gemini、通义、月之暗面、千问、万相、Emu、mj等。对于需要整合多种客户端API的场景很有用。https://github.com/babaohuang/aiclient2api

【new-api】【1.8k stars】类似 one-api，提供 OpenAI 格式接口，支持多种国产大模型，可用于成本优化和API标准化。https://github.com/Calcium-Ion/new-api

## 今日总结
今天主要验证了几个成熟的API聚合和反代工具，这些工具可以帮助您在使用多个AI服务时进行成本控制和统一管理。

建议: 如果您正在使用多个AI服务商的服务，可以考虑部署 one-api 或 aiclient2api 来统一管理和降低成本。
