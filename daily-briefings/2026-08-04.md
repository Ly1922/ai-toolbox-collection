# 每日美工工具挖掘（2026年8月4日）

## 1. 新挖到的美工工具

【amazon-product-studio】【9 stars/2026-07-27更新】开源AI产品摄影工作室，专为亚马逊卖家打造，提供多图片参考上传、预设模板和Webhook支持的场景生成，可作为Flair AI和Booth AI的免费替代方案，支持Stripe计费系统。https://github.com/SamurAIGPT/amazon-product-studio

【amazon-image-studio】AI驱动的亚马逊产品列表图片生成工具，专注于为亚马逊Listing创建高质量的产品图片。https://github.com/zam-2017/amazon-image-studio

【amazon-listing-image-agent】亚马逊产品辅助图片生成的MVP代理工具，包含提示词设计和创意工作流程自动化功能，适合批量处理产品二次图片。https://github.com/hehu369001-in/amazon-listing-image-agent

## 2. 抠图 / 场景合成 / 批量出图

【api】【57 stars/2026-07-24更新】基于BiRefNet技术的状态先进背景移除API，支持图片和视频处理，每张图片约200毫秒，提供26种端点功能包括切口、蒙版导出、放大、面部修复等，MIT许可且可自托管，成本比remove.bg低10倍。https://github.com/useknockout/api

【rembg-product-background-removal】基于rembg(U²-Net)本地运行的批量产品图片背景移除工具，将照片转换为透明PNG切口，使用Backblaze B2作为文件存储，无需付费API。https://github.com/backblaze-b2-samples/rembg-product-background-removal

【image-background-remover】专为电商产品照片设计的批量图片背景移除工具，可快速处理大量商品图片。https://github.com/klattempt/image-background-remover

## 3. ComfyUI / SD 电商工作流

【ComfyUI-RealProductScene】ComfyUI自定义节点，可将真实产品的PNG切口自动合成到AI生成的场景中，支持几何自动适配、接触阴影和GPT场景交换功能。https://github.com/yorimi-tamai/ComfyUI-RealProductScene

【comfyui-product-photo-api】基于Node.js的ComfyUI编排服务，提供电商产品图片处理流水线（背景清理+工作室背景+放大），包含REST API和ComfyUI自定义节点示例。https://github.com/Yusufzdmr/comfyui-product-photo-api

【ComfyUI_HouLai_ToolBox】ComfyUI自定义节点和电商AIGC工作流工具箱，集成多种电商图片处理功能。https://github.com/tusiji232/ComfyUI_HouLai_ToolBox

## 4. 降本相关（反代/免费API）

【Proxy-List-World】【179 stars/2026-08-04更新】开源代理列表工具，通过扫描全球开源列表生成新代理，每2-3分钟更新一次，为访问海外AI服务提供稳定的代理资源。https://github.com/themiralay/Proxy-List-World

【aegis-gateway】Go语言编写的HTTP API网关，提供按客户端限速、断路器、重试抖动、负载均衡等功能，可用于构建自己的AI服务反代。https://github.com/aneskhan/aegis-gateway

今天的挖掘重点是发现了几个专门针对电商场景的AI图片工具，特别是ComfyUI-RealProductScene可以实现产品切口与AI场景的自动合成，非常适合亚马逊产品图片制作。建议试试useknockout/api进行批量背景移除，效率高且成本低。
